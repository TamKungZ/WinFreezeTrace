2. What the software does
-------------------------
WinFreezeTrace runs in the background, keeps a short rolling history of system
counters in memory, and writes a diagnostic report to your disk when it detects
a system stall or an unresponsive foreground application, or when you press the
capture hotkey (Ctrl+Alt+F12). The Manager is an optional tray icon and window
to control it and to browse the reports.

Reports can contain sensitive information. Section 1 of the Privacy Notice
lists what is collected. You are responsible for deciding who may see your
reports and for removing sensitive data before you share them.

4. Administrator rights
-----------------------
The installer needs administrator rights because it installs for all users. It
writes to the program folder and to the machine-wide registry, and, only if you
select them, it adds the install folder to the system PATH and registers
WinFreezeTrace to start when any user signs in. The uninstaller reverses these
changes.

5. Limitations and no guarantee of results
------------------------------------------
- The findings in a report are heuristics: evidence to check, not proof of a
  root cause. A report with few findings does not mean the system is healthy.
- Short spikes, some application or GPU hangs, and hard system locks may go
  undetected or may prevent a report from being written.
- False positives and missed stalls are possible.
- Capturing a report costs CPU and disk, and creating a memory dump may briefly
  suspend the foreground process. Zero performance impact is not guaranteed.
- Security or anti-cheat software may treat process inspection as suspicious.
  Do not run WinFreezeTrace alongside software that forbids it, and check the
  rules of any online game or service before using it there.
